Kebijakan Privasi RAPI AI

Terakhir diperbarui: 18 April 2026
Developer: Fadly Setiawan | fadlystwn@gmail.com

1. Pendahuluan

Selamat datang di RAPI AI ("kami", "aplikasi", atau "layanan"). Kami berkomitmen untuk melindungi privasi Anda dan menjelaskan secara transparan bagaimana kami mengumpulkan, menggunakan, dan melindungi data pribadi Anda.

Dengan menggunakan aplikasi RAPI AI, Anda menyetujui pengumpulan dan penggunaan informasi sesuai dengan kebijakan ini.

2. Data yang Kami Kumpulkan

2.1 Informasi Akun

Email

Untuk autentikasi dan komunikasi

Nama

Untuk personalisasi pengalaman

Password

Disimpan dalam bentuk terenkripsi (hashed)

2.2 Informasi Profil

Role/Posisi

Staff, Senior, Lead, atau Manager

Tipe Perusahaan

Startup, Corporate, atau BUMN

Budaya Kerja

Aggressive, Political, Family-like, atau Toxic

2.3 Data Percakapan

Pesan Chat

Pertanyaan dan percakapan Anda dengan AI

Riwayat Sesi

Histori percakapan untuk konteks

Timestamp

Waktu interaksi

2.4 Data Teknis

Token Autentikasi

JWT access dan refresh tokens

Session ID

Untuk manajemen sesi chat

3. Bagaimana Kami Menggunakan Data Anda

3.1 Penyediaan Layanan

  • Memproses pertanyaan Anda melalui AI (Google Gemini API)
  • Memberikan rekomendasi yang dipersonalisasi berdasarkan profil Anda
  • Menyimpan riwayat percakapan untuk konteks berkelanjutan

3.2 Peningkatan Layanan

  • Menganalisis pola penggunaan untuk meningkatkan kualitas respons
  • Mengoptimalkan performa aplikasi
  • Mengembangkan fitur baru

3.3 Keamanan

  • Autentikasi dan otorisasi pengguna
  • Mencegah penyalahgunaan layanan
  • Rate limiting untuk melindungi sistem

4. Berbagi Data dengan Pihak Ketiga

4.1 Google Gemini API

Data yang dibagikan:

  • Pesan chat Anda
  • Konteks profil (role, tipe perusahaan, budaya kerja)
  • Riwayat percakapan terbatas untuk konteks

Tujuan:

Menghasilkan respons AI yang relevan dan kontekstual

Kebijakan Privasi Google:

https://policies.google.com/privacy

Catatan Penting:

  • Kami TIDAK membagikan email atau password Anda ke Google Gemini
  • Data dikirim melalui koneksi terenkripsi (HTTPS)
  • Kami tidak memiliki kontrol atas bagaimana Google memproses data setelah dikirim

4.2 Pihak Ketiga Lainnya

Kami TIDAK menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga lain untuk tujuan pemasaran.

5. Penyimpanan dan Keamanan Data

5.1 Lokasi Penyimpanan

  • Database: PostgreSQL (data akun dan profil)
  • Redis: Riwayat chat sementara
  • Server: Backend API di infrastruktur cloud

5.2 Keamanan

  • Password: Disimpan dengan hashing (bcrypt)
  • Komunikasi: Enkripsi HTTPS/TLS
  • Autentikasi: JWT dengan expiry time
  • Access Control: Role-based authorization

5.3 Retensi Data

  • Akun aktif: Data disimpan selama akun aktif
  • Chat history: Disimpan di Redis dengan TTL (Time To Live)
  • Setelah penghapusan akun: Data dihapus permanen dalam 30 hari

7. Privasi Anak-anak

RAPI AI tidak ditujukan untuk pengguna di bawah 18 tahun. Kami tidak secara sengaja mengumpulkan data dari anak-anak. Jika Anda adalah orang tua dan mengetahui anak Anda memberikan data kepada kami, hubungi kami segera.

Tanggal "Terakhir diperbarui" di bagian atas akan direvisi. Penggunaan berkelanjutan setelah perubahan berarti Anda menerima kebijakan yang diperbarui.
