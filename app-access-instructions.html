App Testing Guide

Step 1: Login

  1. Launch RAPI AI app
  2. Enter test credentials above
  3. Tap "Login"
  4. You should see the home screen with chat interface

Step 2: Test Core Features

Chat Functionality

  1. Tap the chat input field at the bottom
  2. Try these sample questions:
    • "Bagaimana cara merespons email atasan yang terkesan menyalahkan saya?"
    • "How should I handle a passive-aggressive colleague?"
    • "Saya ditawari promosi tapi harus pindah tim, bagaimana memutuskan?"
  3. Observe AI response with multiple options and recommendations
  4. Check that responses are contextual to the profile

Session Management

  1. Tap the menu icon (top left)
  2. View chat history/sessions
  3. Start a new chat session
  4. Switch between sessions

Profile Management

  1. Navigate to Profile screen
  2. View user information
  3. Try updating profile fields
  4. Changes should be saved successfully

Settings

  1. Navigate to Settings screen
  2. Test theme switching (Light/Dark/System)
  3. View app version and about info
  4. Account Deletion (optional - creates new test needed):
    • Tap "Delete Account"
    • Confirm deletion
    • Account and data should be removed

Known Limitations

Rate Limiting

  • 100 chat requests per minute per user
  • 200 history requests per minute
  • If exceeded, user will see rate limit error

Backend Dependency

  • App requires active internet connection
  • Backend API must be running
  • If backend is down, app will show connection error

AI Response Time

  • Responses typically take 2-5 seconds
  • Longer for complex questions
  • Timeout after 30 seconds

Backend Status

Production Backend

  • URL: https://api.rapi-ai.web.id
  • Status: Active
  • Health Check: https://api.rapi-ai.web.id/health

API Endpoints Used

  • POST /api/auth/login - Authentication
  • POST /api/auth/register - Registration
  • GET /api/users/profile - Get user profile
  • PUT /api/users/profile - Update profile
  • POST /api/chat - Send chat message
  • GET /api/chat/history - Get chat history
  • GET /api/chat/sessions - Get user sessions
  • DELETE /api/users/account - Delete account

Troubleshooting

Issue: Cannot Login

  • Check: Internet connection
  • Check: Backend API status
  • Try: Use alternative test account or create new one

Issue: No AI Response

  • Check: Rate limit not exceeded
  • Check: Backend API is running
  • Wait: 30 seconds for timeout, then retry

Issue: App Crashes

  • Report: Send crash logs to fadlystwn@gmail.com
